## Concurrency lessons from this session

- Six agents in one checkout works when file ownership is disjoint and stated
  in every brief; the collisions that happened were on `sqlite.ts` (two
  agents, different facets; resolved by re-read-before-edit) and on docs
  (roadmap edited by two agents; the integrator deduplicated).
- Do not run `pnpm test` (which rebuilds `dist`) or `pnpm build` while the
  Python compat tests or the two-process SQLite tests are running elsewhere;
  three transient failures came from that. Treat a single red result in a
  busy checkout as suspect until it repeats alone.
- Agent reports truncate at roughly 4k characters; ask for the tail when a
  report ends mid-sentence, it has carried the most important finding twice.
